# VTT App (Virtual Tabletop)

A complete virtual tabletop application built for D&D 5e, with grid mapping, real-time token movement, chat, dice rolling, and comprehensive character sheets.

## Tech Stack
- Backend: Node.js, Express, Socket.IO, SQLite
- Frontend: React, Vite, TailwindCSS, Zustand

## Setup Instructions

1. Install dependencies:
   `npm run install-all`

2. Initialize the database:
   `npm run setup`

3. Start the application (both frontend and backend):
   `npm run start-all`

   The frontend will be available at `http://localhost:5173` (or the port Vite chooses), and the backend at `http://localhost:3001`.
